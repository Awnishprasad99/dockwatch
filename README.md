# DockWatch

Docker Server Monitoring CLI for Linux.

Made by Awnish.

## What is DockWatch?

DockWatch is a lightweight command-line tool that helps Linux server administrators monitor Docker servers.

It provides information about:

- Docker Engine status
- Docker version
- Containers
- Running containers
- Stopped containers
- Container CPU usage
- Container memory usage
- Server CPU usage
- Server RAM usage
- Server disk usage
- Docker disk usage

## Commands

```bash
dockwatch
dockwatch ps
dockwatch stats
dockwatch disk
dockwatch info
dockwatch system
dockwatch help
dockwatch version
